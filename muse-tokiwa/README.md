# ときわ万年筆（muse-tokiwa）

無垢の真鍮で作った架空の万年筆「ときわ」の製品ページです。ブランド・価格・仕様はすべて架空で、実在の製品・店舗とは関係ありません。

## 設計の意図

- 素材（真鍮）の性質そのものをページの背骨にしました。塗装がないからこそ起きる「経年変化」を欠点ではなく主役に置き、色は真鍮の金色と、使い込んだ飴色、インクの色から取っています。
- 罫線入りの紙の上で実際に線を引ける「試し書き」を置きました。ペン先の太さとインクの色を切り替えると線が変わる、製品ページらしい体験をブラウザ内だけで完結させています（保存・送信はしません）。
- 価格は「組む」形にしました。名入れ・ギフト箱・予備インクの追加で合計がその場で変わり、購入ボタンはデモであることを明示して止まります。
- 書体は見出しに端末標準の明朝体、本文にゴシック体。画像は使わず、万年筆の絵は SVG で描いています。

## 素材・フォントの出所

- フォント：端末標準のフォントのみ（外部フォントなし）
- 画像：外部画像なし。万年筆とブランドマークは自作の SVG、試し書きの線は利用者がその場で引くもの
