# おつかい（muse-otsukai）

家族で共有する買い物メモアプリ「おつかい」（架空）の紹介ページです。お題は [briefs/lifestyle-app.md](../briefs/lifestyle-app.md)。アプリ・家族・料金はすべて架空で、実在のストアでは配布していません。

## デザインの意図

買い物メモそのものをページの主役にしました。説明を読む前に、まず触れます。

- ヒーロー：右に電話の枠に入った体験デモを置き、実際にメモの追加とチェックができます。「たのむ人／いく人」の役割を切り替えると、できる操作が変わります（追加はたのむ人だけ、チェックはいく人だけ）。役割で操作を分けることが、このアプリの設計の核なので、デモでも再現しました。
- 色：紙 `#fbfbf8`、墨 `#232620`、メモの青 `#2b50aa`、チェックの赤 `#d64533`。赤はチェック印と「困りごと」の帯だけに使い、買えた印の気持ちよさに寄せています。
- 文字：端末のゴシック1系統。件数表示は等幅数字です。
- 構成：困りごとは3枚のカード、できることは「たのむ／買う／分け合う」の3行の表組みにしました。どちらも買い物の流れ（頼む→買う→精算）に対応しています。セクションごとのフェードインは入れていません。
- 個人情報の節では、アカウントなし・位置情報を集めない・広告に使わない、という「しないこと」を先に書きました。

## 画像とフォントの出典

- 画像ファイルはありません。買い物かごの印と `favicon.svg` は SVG で描きました。電話の枠と画面は HTML/CSS で組んでいます。
- フォントは同梱していません。閲覧する端末のフォントを使います。外部への読み込みはありません。
