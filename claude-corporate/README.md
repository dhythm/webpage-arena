# claude-corporate

Claude Code が作った、架空の企業のコーポレートサイトです。`index.html`・`style.css`・`main.js` の3ファイルで動きます。外部から読み込むのは Google Fonts だけで、画像ファイルは使っていません。

**KAISŌ Materials 株式会社**：海藻を原料にしたコンクリートと断熱材をつくる素材メーカー

## デザインメモ

- **対象と目的**：建築家、デベロッパーのサステナビリティ担当者、自治体、採用候補者に、サンプルと技術資料を請求してもらう。
- **色**：打放しの影 `#121310`、コンクリート `#E6E3DC`、墨 `#161714`。差し色は干し昆布の色 `#A8873A` ひとつだけ。
- **書体**：
  - 和文は Noto Sans JP の Black で、大きく詰めて組む。
  - 欧文と数字は Archivo。幅可変軸を広げて使い、土木・工業製品の刻印のような印象にしている。
- **いちばん大胆な部分**：ヒーローの打放しコンクリートの壁。WebGL のシェーダーで高さマップをつくり、低い角度の光で照らしている。
  - 高さマップに入っているもの：型枠の継ぎ目、セパ穴、気泡、合板の木目の転写、海藻繊維。
  - 光はカーソルを追う。触っていないときは、壁の上をゆっくり漂う。
- **構成**：
  - 主張と数値
  - 素材2種：断面と表面の拡大図は Canvas で描画
  - 4工程：順序があるので、ここにだけ番号を付ける
  - 炭素台帳：用途で絞り込める表
  - お知らせ、会社概要、採用、サンプル請求
- **やめたこと**：灰色の地に巨大な文字だけを置いたヒーロー（前作）、ほぼ黒の地にアシッドグリーン、全セクションの連番、3事業を同じカードで並べる構成。

## アクセシビリティと負荷

- `prefers-reduced-motion` のときは、光を固定して描画ループを止める。
- WebGL が使えない環境では CSS のグラデーションに切り替える。
- ヒーローが画面外にあるときやタブが非表示のときは、描画を止める。シェーダーが重いので DPR は 1.5 までに制限している。
- 狭い画面では、炭素台帳を「建物」と「固定した炭素」の2列にする。
- 企業・人物・建物・数値はすべて架空。サンプル請求フォームはデモなので、送信しない。
