# claude-corporate

Claude Code が [frontend-design スキル](https://github.com/anthropics/skills/tree/main/skills/frontend-design) に沿って作った、架空の企業のコーポレートサイトです。HTML ファイル1つで完結していて、外部から読み込むのは Google Fonts だけです。`index.html` をブラウザで開けば表示できます。

**KAISŌ Materials 株式会社**：海藻を原料にしたコンクリートと断熱材をつくる会社のホームページ

## デザインメモ

- **対象と目的**：建築家、デベロッパーのサステナビリティ担当者、採用候補者。サンプルと技術資料の請求が目的。
- **色**：打放しコンクリート `#D9D6D0`、昆布 `#2F2B1C`（文字色。中立的な黒の代わり）、海松 `#6B6A3A`、潮 `#1F4E5F`（リンクとボタンだけに使う）
- **書体**：見出しは極太の Dela Gothic One、本文は UD 書体の BIZ UDPGothic
- **いちばん大胆な部分**：「海から、建てる。」の文字を、海藻繊維入りのコンクリートで打ったような質感で見せる。背景は打放しの型枠目地とPコン穴。
- **やめたこと**：ほぼ黒の背景にアシッドグリーンのアクセント、等幅フォントの小ラベル、全セクションの連番（番号は実際に順序がある「つくりかた」の4工程だけに使用）、3事業を同じカードで並べる構成（手に取れる2素材は「サンプル」として、炭素台帳は表として見せる）

コンクリートと断熱ボードのテクスチャは SVG（feTurbulence と乱数で描いた繊維）をデータ URI として埋め込んでいます。
