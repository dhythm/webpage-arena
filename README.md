## ローカルプレビュー

Node.js 20.11以降（検証は24）。ランタイムの依存パッケージはありません。

```sh
npm run dev
```

- 選択画面: http://127.0.0.1:4173/
- 商品LP: http://127.0.0.1:4173/gpt-nagi/
- 企業HP: http://127.0.0.1:4173/gpt-umi/

`PORT=4180 npm run dev` でポートを変更できます。サーバーはlocalhostのみで待ち受けます。

## ビルド・検証

```sh
npm run build      # dist/ に2作品と選択画面を出力し、HTMLのローカル参照先を検査
npm run preview    # dist/ をプレビュー（devサーバーとは別に起動）
```

ブラウザテスト用の開発依存だけを入れる場合:

```sh
npm ci
npx playwright install chromium
# 別ターミナルで npm run dev を起動した状態で:
npm test
npm run test:a11y
```

`npm test` は320 / 390 / 768 / 1024 / 1440 / 1920pxのレイアウト、390 / 1440pxのDPR 2画像選択、主要操作、キーボード、reduced-motion、外部通信の不在を検査します。`npm run test:a11y` はaxe-coreのWCAG 2 A/AA・2.1 A/AA・2.2 AAルールを、両サイトのページとフォームダイアログ、390 / 1440pxで検査します。自動監査は完全なWCAG準拠を保証するものではありません。

実行証跡: [ブラウザ検証結果](qa/report.json) / [アクセシビリティ監査](qa/accessibility.json)。QAスクリーンショットはローカルの `qa/screenshots/` に生成し、PNG・WebPともGit管理の対象外です。WebP変換の再現には `cwebp`（macOS: `brew install webp`）を入れ、`npm run screenshots:webp` を実行します。実サイトが使用する画像は各作品の `assets/` に保存しています。

## 実装について

- HTML / CSS / JavaScriptのみ。両フォルダは独立し、共通のビルド環境やフレームワークを要求しません。
- 日本語コピー、ロゴ、配色、図版、試聴音は各ブランド用に制作。写真2点は組み込みimagegenで生成しました。
- 写真は1536×1024と768×512のWebP。`srcset` / `sizes`、画像寸法指定、ファーストビューの優先読込、下部の遅延読込を設定しています。元の生成PNGは含みません。
- 日本語・英字フォントは必要文字のWOFF2サブセットとして自己配信。実行時に外部の画像CDNやGoogle Fontsへ接続しません。
- スキップリンク、可視フォーカス、ネイティブdialogとdetails、フォーカス循環・復帰、Esc、ARIAの状態通知、動きの一時停止、`prefers-reduced-motion` に対応。
- 音はクリック時にWeb Audio APIで合成。自動再生せず、ページが非表示になると停止します。実際のスピーカーの音質を再現するものではありません。
- 商品・企業・価格・仕様・研究・データ・記事は架空。フォームはブラウザ内の体験のみで、送信・保存・決済を行いません。

詳しい意図は [DESIGN.md](DESIGN.md)、画像生成プロンプト・フォント出典は [ASSETS.md](ASSETS.md) に記載しています。
