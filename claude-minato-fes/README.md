# 港暮らしフェス 2027（claude-minato-fes）

架空の港町・凪浦で開く、食と音楽の1日限りのフェスの告知ページです。お題は [prompts/event.md](../prompts/event.md)。凪浦町、鴎ヶ崎町、凪浦港、出演者、出店者はすべて架空です。チケットはデモで、送信も決済もしません。

- 日時：2027年5月16日（日）10:00 開場、20:00 閉場
- 会場：凪浦港 第二埠頭と旧倉庫街（架空、凪浦町港通り3丁目）

## デザインの意図

ページを港の断面として組みました。上から空、岸壁、海の順に重ねています。

- ヒーロー：空にロープを張り、国際信号旗を6枚吊るしました。左から M、I、N、A、T、O と読めます。旗は読み込み時に数回揺れたあと止まり、`prefers-reduced-motion` のときは揺れません。そのすぐ下に、黄色い安全線を引いたコンクリートの岸壁の帯を置き、海の帯に日時と会場を書きました。
- 色：海 `#14466b`、空 `#e3ecf0`、船体の白 `#f7f9f8`、墨 `#17232d`、信号の黄 `#f3c536`、浮標の赤 `#c2352a`、岸壁 `#cfd5d6`。黄は岸壁の安全線と区画番号に、赤は閉会の汽笛と海側の注意事項だけに使っています。
- 文字：端末の日本語ゴシック（ヒラギノ角ゴ、Noto Sans CJK JP、游ゴシックなど）を1系統だけ使い、太さの差で役割を分けました。見出しは岸壁に描く文字を思わせる極太で、時刻は等幅数字にしています。
- 番号：区画番号（A-1 など）とタイムテーブルの時刻だけです。どちらも会場で実際に探すための情報です。
- 動き：ヒーローの旗の揺れと、入場券の見本が出るときの短い動きの2か所だけです。セクションごとのフェードインは入れていません。
- 操作：タイムテーブルで印をつけた演目は、時刻順に「あなたの印」へまとまります。出店は種類で絞り込むと、配置図の区画も連動します。チケットは種類と枚数から合計を出し、画面の中に入場券の見本を表示するだけです。

## 画像とフォントの出典

- 画像ファイルはありません。信号旗、埠頭の配置図、経路の略図、`favicon.svg` は、このページのために SVG で手描きしました。
- フォントは同梱していません。閲覧する端末の日本語フォントを使います。外部への読み込みはありません。
