FAQ

よくある
ご質問

光だけで本当に起きられますか？

個人差はありますが、モニター120名のうち87%が「アラーム音より自然に起きられた」と回答しています。心配な方は、起床時刻にやさしい鳥の声を鳴らす設定も可能です。

遮光カーテンの部屋でも使えますか？

むしろ遮光カーテンの部屋にこそおすすめです。外光に左右されず、毎朝同じ光のリズムで体内時計を整えられます。

和紙が汚れたり破れたりしたら？

シェードは工具なしで取り外せます。保証期間中は1回無料で、それ以降も実費にて職人が張り替えます。

普段の照明としても使えますか？

はい。ダイヤルを押し込むと常夜灯・読書灯として点灯します。回すと明るさと色を無段階に調整できます。

停電したら設定は消えますか？

内蔵のコイン電池で時刻と設定を約2年間保持します。電源が戻れば、いつも通りの朝が訪れます。
