# claude-code

Claude Code が制作したデモページです。すべて架空の商品・企業です。外部依存は Google Fonts のみで、各ページは単一の HTML ファイルで完結しています。

| ページ | 内容 |
| --- | --- |
| [`lp/`](lp/index.html) | **TOKI** — 30分かけて朝日を再現する、和紙の日の出目覚ましランプのランディングページ。スクロールに連動して夜明けが進むヒーロー、日の出シミュレーター、カラー切替、予約カウントダウンなど。 |
| [`corporate/`](corporate/index.html) | **KAISŌ Materials 株式会社** — 海藻由来のカーボンネガティブ建材メーカーのコーポレートサイト。Canvas の等高線アニメーション、スクロールで浮かび上がるステートメント、事業ホバープレビュー、ニュースフィルタ、フォームバリデーションなど。 |

ブラウザで `index.html` を直接開くだけで閲覧できます。
