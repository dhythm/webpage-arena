# claude-code

Claude Code が [frontend-design スキル](https://github.com/anthropics/skills/tree/main/skills/frontend-design) に沿って作ったデモページです。商品も企業も架空です。各ページは HTML ファイル1つで完結していて、外部から読み込むのは Google Fonts だけです。`index.html` をブラウザで開けば表示できます。

| ページ | 内容 |
| --- | --- |
| [`lp/`](lp/index.html) | **TOKI**：起きる30分前から、和紙越しに朝日を再現する目覚ましランプのランディングページ |
| [`corporate/`](corporate/index.html) | **KAISŌ Materials 株式会社**：海藻を原料にしたコンクリートと断熱材をつくる会社のホームページ |

## デザインメモ

### TOKI（lp/）
- **対象と目的**：寝起きのつらさに悩む30〜40代の都市生活者。先行予約が目的。
- **色**：夜明け前の寝室の壁「青鈍」`#D6DBE2`、藍墨 `#252A3B`、灯り `#FFC680`（光の表現にだけ使う）、檜 `#C9A06C`
- **書体**：見出しは鉛筆書きのような Klee One（枕元のメモのような声）、本文は Zen Kaku Gothic New
- **いちばん大胆な部分**：ヒーローにある木のダイヤル。回すと30分の夜明けが早送りされ、ランプの光の色、時刻、部屋の壁の色が変わる。キーボードの矢印キーでも操作できる。
- **やめたこと**：スクロールに連動する日の出（見る人が受け身になる演出）、クリーム色の背景にテラコッタのアクセント、各セクションの英字の小見出し、フェードインの連発、マーキー、カウントダウン

### KAISŌ Materials（corporate/）
- **対象と目的**：建築家、デベロッパーのサステナビリティ担当者、採用候補者。サンプルと技術資料の請求が目的。
- **色**：打放しコンクリート `#D9D6D0`、昆布 `#2F2B1C`（文字色。中立的な黒の代わり）、海松 `#6B6A3A`、潮 `#1F4E5F`（リンクとボタンだけに使う）
- **書体**：見出しは極太の Dela Gothic One、本文は UD 書体の BIZ UDPGothic
- **いちばん大胆な部分**：「海から、建てる。」の文字を、海藻繊維入りのコンクリートで打ったような質感で見せる。背景は打放しの型枠目地とPコン穴。
- **やめたこと**：ほぼ黒の背景にアシッドグリーンのアクセント、等幅フォントの小ラベル、全セクションの連番（番号は実際に順序がある「つくりかた」の4工程だけに使用）、3事業を同じカードで並べる構成（手に取れる2素材は「サンプル」として、炭素台帳は表として見せる）

コンクリートと断熱ボードのテクスチャは SVG（feTurbulence と乱数で描いた繊維）をデータ URI として埋め込んでいます。
