海から、
建てる。

KAISŌ Materials は、海藻を原料にしたコンクリートと断熱材をつくっています。海藻が海で吸った炭素を、建物の中に何十年も閉じこめます。

サンプルを請求する 素材を見る

建物を、炭素の貯蔵庫にする。

世界のCO₂排出量のおよそ4割は、建物をつくり、使うことから出ています。なかでもセメントの製造は、それだけで排出量の約8%を占めます。

一方、コンブやアカモクなどの海藻は、肥料も淡水も使わずに育ち、育つあいだに海中のCO₂を吸収します。

私たちは海藻をセルロース、アルギン酸、ミネラルの3つに分け、セメントや石油由来の断熱材の代わりに使います。海藻の吸った炭素は、建物が建っているかぎり外に出ません。

素材

どちらの素材も、10cm角のサンプルを無料でお送りします。設計中の物件があれば、仕様に合わせた試験データもご用意します。

KAISŌ CRETE　断面

海藻コンクリート KAISŌ CRETE

セメントの最大30%を、海藻を焼いた灰から取り出したミネラルに置き換えました。強度はそのままで、1m³あたり38kgのCO₂を閉じこめます。

KAISŌ FIBER　表面

海藻断熱ボード KAISŌ FIBER

海藻の繊維を、海藻から取ったアルギン酸で固めた断熱材です。石油を使わず、ホルムアルデヒドも含みません。湿気を吸ったり吐いたりして、室内の湿度を整えます。

建物ごとの炭素台帳

KAISŌ の素材を使った建物には、どの海で育った海藻が、どれだけの炭素を閉じこめているかを記録した台帳をお渡しします。第三者機関の検証を受けているので、そのままESG開示やScope3の報告に使えます。

閉じこめた出した

海藻が、建物になるまで。

養殖から施工後の記録まで、すべて自社と協力先で行います。だから炭素の流れを最後まで追えます。

  1. 育てる

    全国14の漁協と組み、冬のあいだにコンブやアカモクを養殖します。漁業者にとっては、漁閑期の新しい収入になります。

  2. 分ける

    函館の研究所で開発した低温プロセスで、海藻をセルロース、アルギン酸、ミネラルの3つに分けます。

  3. 素材にする

    石巻と唐津の工場で、ミネラルはコンクリートの混和材に、繊維とアルギン酸は断熱ボードになります。

  4. 記録する

    建物ごとに炭素台帳をつくり、解体してリサイクルするまで固定量を追いかけます。
