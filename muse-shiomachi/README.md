# 潮待ち（muse-shiomachi）

架空の離島・漣島にある一棟貸しの宿「潮待ち」の案内ページです。お題は [briefs/inn.md](../briefs/inn.md)。漣島、深浦、宿、料金、潮位はすべて架空で、予約フォームはブラウザの中で完結するデモです（送信・決済はしません）。

## デザインの意図

滞在の組み立てそのものが潮で決まる宿なので、ページの背骨も潮の曲線にしました。

- ヒーロー：画面の下半分を潮の曲線（SVG）が横切り、満潮と干潮の印を置きました。下は深い海色に塗り、ページを開いた瞬間に「水位」が伝わるようにしています。セクションごとのフェードインは入れていません。
- 色：海の深緑 `#17434b`、混色 `#3d7a80`、薄い水色 `#dcebe8`、紙 `#f2f4f1`、墨 `#1d2b2c`。潮の印だけに赤 `#c2502e` を使い、満潮・干潮の区別と船の目安にだけ現れます。
- 文字：見出しは端末の明朝体（ヒラギノ明朝、游明朝、Noto Serif CJK JP など）、本文は端末のゴシック。時刻と料金は等幅数字にしています。
- 操作：日付を選ぶと、その日の満潮・干潮の目安（約12時間25分の周期で機械的に計算する架空の値）と船の出入りの見通しを表示します。料金デモは泊数・人数・食事から合計を出し、「予約メモ」を画面に表示して終わります。
- 過ごし方は「干潮／満ちてくる／満潮」の3つの状態で分けました。番号付きの手順ではなく、潮の状態がそのまま目次になっています。

## 画像とフォントの出典

- 画像ファイルはありません。潮の曲線と `favicon.svg` は、このページのために SVG で描きました。
- フォントは同梱していません。閲覧する端末のフォントを使います。外部への読み込みはありません。
