# claude-kakehashi

Claude Code（Claude Opus 5.5）が [prompts/saas-lp.md](../prompts/saas-lp.md) のお題から作った、架空の業務 SaaS のランディングページです。`index.html`・`style.css`・`main.js` と、同梱フォント 1 つで動きます。外部から読み込むものはありません。

**カケハシ**：中小企業の請求書と入金消込を、一つの画面で見る業務 SaaS（架空）

## デザインメモ

- **対象と目的**：経理が1〜2人の会社の経営者または経理担当。月末に表計算の請求台帳と銀行の明細を見比べている人に、消込が一つの画面で終わる様子をデモで触ってもらう。
- **題材から決めたこと**：通帳の記帳行（ドット印字の半角カナ名義「ﾌﾘｺﾐ ｶ)ﾔﾏﾈｾｲｻｸｼﾖ」）、帳簿や伝票の緑の罫、消込済の朱の印、締めの二重線。
- **色**：伝票紙 `#f4f7f5`、罫線緑 `#1e6656`、薄罫 `#cfe0d8`、墨 `#1d2624`、朱肉 `#c2352b`、通帳面 `#e3eef0`。朱は「消込済」の印と、ずれ（差額・名義）の表示にだけ使う。
- **書体**：本文と見出しは端末の日本語ゴシック。通帳の記帳行だけ DotGothic16 のサブセット（半角カナ・英数・記号）を使う。
- **いちばん大胆な部分**：ヒーロー。請求書の紙片と通帳の記帳行が線で結ばれ、消込済の印が押される。記帳行は左から印字され、線が引かれ、印が押される一続きの動きで、ページの自動的な動きはここだけ。
- **構成**：課題（記帳と請求書がずれる三つの例を表で）→ 画面（CSS で描いた製品画面と三つの注記）→ 機能（「カケハシがすること／あなたがすること」の帳簿表）→ デモ → 料金（お見積書の書式）→ FAQ。
- **やめたこと**：同じ角丸カードを並べた機能紹介、3 列の料金カード、セクションごとのフェードイン、全部大文字の英字ラベル、見出しの一語だけの色替え。順序のない内容には番号を付けていない。

## デモ（#demo）

1. 入金明細から一行を選ぶ。合いそうな請求書に「候補」の印がつく。
2. 「候補の請求書を選ぶ」か、請求書のチェックを自分で入れる。
3. 差額が 0 なら「消込む」、880 円以下の不足なら「差額◯円を手数料として消込む」。利息は「受取利息として外す」。
4. 消込むと行に消込済の印が押され、下に仕訳案が一行ずつ残る。「最初からやり直す」で戻る。

名義が未登録の入金（ﾐﾅﾄｳﾝｿｳ(ﾄﾞ）は金額だけで候補を出し、消込むと名義を覚えます。すべてブラウザの中で動き、送信・保存はしません。

料金の「お見積書（架空）」は、枚数と人数を入れると合うプランと税込の月額を計算します。こちらも送信しません。

## アクセシビリティと負荷

- デモの入金明細は `aria-pressed` 付きのボタン、請求書は本物のチェックボックス。結果は `aria-live` で読み上げる。
- `prefers-reduced-motion: reduce` のときは、ヒーローも印も動かさず最終状態で表示する。
- 画像ファイルは使わず、製品画面は HTML/CSS、ロゴとヒーローの線は SVG で描いている。
- サムネイル撮影は `meta.json` の `thumbWait`（`#hero-ledger[data-settled]`）で、ヒーローの動きが終わってから撮る。
