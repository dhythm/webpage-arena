# 採用デスク

採用担当者と面接担当者が、候補者ごとの進捗と次の対応を同じ机の上で確認する、という架空の採用管理サービス。登場する人物、記録、サービスはすべて架空です。

書類フォルダの青をブランド色に、ラベルの紺を文字色に使用しました。端末の日本語ゴシック体で、氏名と工程を読み分けやすくしています。冒頭にデスクトップ風の書類イラスト、その下に操作できる選考ボード、続いて使い方とよくある質問を配置。狭い画面では列を縦に並べます。

カードを開くと引き継ぎメモと次の対応が表示され、次の工程へ進めると所属列と件数が変わります。登録・通信・保存はありません。初期化ボタンまたは再読み込みで元に戻ります。アニメーションは使いません。

書類・人物・付箋のイラスト（desk.svg）とアイコンは本作品用の自作SVGです。外部素材や配布フォントは使用していません。index.html を直接開いて体験できます。
