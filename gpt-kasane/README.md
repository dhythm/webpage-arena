# Kasane（カサネ）

小さな会社の経理担当者に向けた、証憑照合クラウドのランディングページです。サービス、取引先、日付、金額はすべて架空です。

淡い青の方眼は帳簿の罫線、紺は記入するインク、藤色は重ねた複写紙を表します。冒頭の分解図では領収書と帳簿が別々の層をなし、照合台では同じ項目を左右に揃えて読み比べられます。日本語には端末の角ゴシック、英数字にはArialなどのサンセリフを使用。数字の比較には等幅数字を指定しました。

図から照合デモ、操作手順、質問へと読み進める構成です。デモには全項目一致・金額違い・日付違いの例があり、「照合する」を押すと差がある行に印を付け、判定を文章でも伝えます。ブラウザ内だけで動作し、通信・保存・決済はしません。

トレーの図（`tray.svg`）、ロゴ、操作記号、方眼は本作品用にSVGとCSSで制作しました。外部画像や配布フォントは使用していません。
