# 青時（あおどき）

駅から徒歩数分の、席数の少ない蕎麦屋のランディングページ。お題は [`prompts/restaurant.md`](../prompts/restaurant.md)。店・駅名（水縹線 宵坂駅）・地名（宵坂市灯町）・価格・空席はすべて架空です。

## デザインの意図

題材の「青時」は、日が沈んだあと空が青く残る短い時間のこと。店はその時間にのれんを出す、という一点からページを組み立てています。

- 色: 空の青（`#3a5680` から `#101a2e` へ）、そば粉の白 `#e4e6e1`、墨 `#182235`、店の灯り `#f2c062`、のれんの紺 `#1c3a6b`。暖色は「窓の灯り」と予約ボタンだけに使い、面には置かない。
- 動き: スクロールするにつれて背景が夕方の青から夜の紺へ沈み、ヒーローの星が少しずつ見えてくる。ページを下りることが、仕事帰りに店へ向かう時間の経過になる。ヒーローでは高架を電車がときどき横切り、のれんが揺れ、窓の中で湯気が上がる。道順の破線は画面に入っているあいだだけ歩くように流れる。`prefers-reduced-motion` ではすべて止まる。
- 文字: 見出し・品書き・予約票は明朝（さわらび明朝）。ヒーローのコピーと品書きの木札は縦書き。本文と操作は端末のゴシック。
- 品書き: 壁に掛けた木札のように、名前と短い添え書きを縦に並べ、値段は札の下に置く。
- 席: 細長い店内の見取り図（SVG）。席の種類にマウスやキーボードで触れると、図の中の該当する席に灯りがつく。
- 時間: 16時から24時までの空の色の帯に、火曜〜金曜の営業時間と「いま」の位置を重ねる。ページ上部の一行は、時刻からのれんが出ているかどうかを出す（JS が動かないときは火〜金／土日祝／休みの説明文のまま）。
- 予約: フォームの結果は、駅から店までの切符の形をした「予約票（見本）」としてページ内に出るだけ。送信・保存はしない。空席数は日にちと時刻から決まる仮の数字。時刻の枠は、選んだ日にちの営業時間（火〜金は夜、土日祝は昼と夜）から 30 分おきに組み立て、最後の注文より後の枠は出さない。

番号付きの見出しや、全セクション一律のフェードインは使っていない。

## 時刻と祝日

- 営業日・時刻枠・上部の一行の文は `hours.js` の純関数で決める。時刻は `window.__AODOKI_NOW`（ISO 文字列か Date、ページ読み込み前に置く）か、読み込み後の `window.Aodoki.setNow(...)` で差し替えられる。どちらも無いときだけ端末の時計を使う。
- 祝日は `hours.js` の `HOLIDAYS`（2026〜2027 年、振替休日・国民の休日を含む）。出典: 内閣府「国民の祝日について」と、春分・秋分の日は国立天文台「暦要項」。祝日が月曜に当たる日は定休日を優先してお休み。
