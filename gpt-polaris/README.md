# 深夜喫茶 ポラリス

宵見坂で夕方から開く夜喫茶のページ。店、所在地、料理、価格、営業時間など、設定はすべて架空です。

藍色の夜空に青いソーダ、月色のアイス、さくらんぼを重ねました。星図の軌道とグラスの縁の細い線で、看板メニューをひとつの星座に見立てています。見出しは明朝体、図版のキャプションは欧文イタリック、メニューの説明は小さくても読みやすいゴシック体です。

夜空を抜けると、紙色の品書きに切り替わります。三つのボタンで飲みもの・甘いもの・軽食をその場でめくる構成です。送信や保存は行いません。細い画面では図版と文章、メニュー項目を縦に並べます。ページ内移動は動きを減らす設定に従います。

メインのソーダ、星空、三日月の看板、各料理の挿絵はこの作品のために描いたSVGです。画像・フォントを含め外部素材は不使用。書体は端末にある游明朝、ヒラギノ、Noto Serif CJK JP、Georgia、游ゴシック、メイリオなどを使用します。
