# のまみち（claude-nomamichi）

夜道の明るさと人通りの目安を地図で見る、歩行者向けの**架空の**アプリの LP です。お題は `prompts/app-lp.md`。実在のストアには出しておらず、ダウンロードボタンはページ内にデモの結果を出すだけです。

## デザインの意図

- 題材：夜道、街灯、地図、帰り道、明るさの濃淡。ページ全体を「夜の地図」として組みました。
- 色：背景は夕暮れの紺（`#17233a`）から深夜の紺（`#090f1b`）へ、下へ行くほど暗くなります。アクセントは 2 色の灯りだけ。ナトリウム灯の橙（`#f4b860`）は店の灯りと「明るい道」、LED 街灯の青白（`#d6e6ff`）は街灯と現在地です。暗い区間は紺に近い灰（`#3a4a68`）。暖色クリームや黒＋アシッドグリーンは使っていません。
- 文字：見出しは端末の明朝（BIZ UDPMincho / ヒラギノ明朝 / Noto Serif CJK）で、夜の静けさと標識のような落ち着きを出し、本文と UI は端末の UD ゴシック／ヒラギノ角ゴ／Noto Sans CJK。Web フォントは同梱していません。
- 構成：ヒーローに操作できる地図（時刻スライダーで 19 時〜翌 2 時へずらすと、店の灯りが消え、人通りの点が減る）→「目安であって安全の保証ではない」という注意 → 使い方（番号ではなく、暗い紺から街灯色へ明るくなる経路線の上の 3 つの地点）→ 画面イメージ（街灯の高さのように少しずつずらして並べる）→ 位置情報の扱い → 対応 OS → ダウンロード案内（デモ）。
- 動き：常時動くのはヒーローの「歩く点」だけで、停止ボタンがあります。`prefers-reduced-motion: reduce` のときは最初から止まっており、灯りのトランジションも切ります。セクションごとのフェードインはありません。
- 書かないもの：受賞、レビュー、利用者数。OS 名（Lumina OS、Kairo、Kairo Wear）、駅名、通りの名前、画面の数値はすべて架空です。

## ファイル

- `index.html`、`style.css`、`main.js`
- `img/screen-*-260.webp` / `img/screen-*-520.webp`：画面イメージ（表示幅 220〜240px 向けの 1x と 2x）
- `thumb.webp`：`npm run thumbs -- claude-nomamichi` で生成
- `meta.json`

## 画像・フォントの出典

- ヒーローの地図はページ内のインライン SVG で、この作品のために描いたオリジナルです。
- 画面イメージ 3 枚は、この作品のために SVG で描いたオリジナルのイラストを、Playwright（Chromium）で 260px 幅と 520px 幅の WebP に書き出したものです。写真や外部素材は使っていません。画面内の文字は書き出し時の端末フォント（Noto Sans CJK JP、SIL Open Font License 1.1）でラスタライズされています。
- フォントファイルは同梱していません。表示には閲覧者の端末にあるフォントを使います。
