# claude-lp

Claude Code が作った、架空の商品のランディングページです。`index.html`・`style.css`・`main.js` の3ファイルで動きます。外部から読み込むのは Google Fonts だけで、画像ファイルは使っていません。

**TOKI**：起きる30分前から、和紙ごしに朝日を再現する目覚ましランプ

## デザインメモ

- **対象と目的**：寝起きのつらさに悩む30〜40代の都市生活者に、先行予約してもらう。
- **ページ全体の筋書き**：6:00〜6:30 の寝室。夜の色（ヒーロー、ある朝の30分、予約）と朝の壁の色（説明、素材、仕様）を交互に置き、夜の側には必ず灯りの色がある。
- **色**：夜 `#0D0C1D`、朝の壁 `#EFEEE9`、文字 `#1C1B2B`。暖色（`#FF9A3D`→`#FFD49C`→`#FFF1DC`）は、光っているものにだけ使う。
- **書体**：見出しは Shippori Mincho B1。ヒーローの見出しは縦書き。本文と操作部分は IBM Plex Sans JP。
- **いちばん大胆な部分**：ヒーローのランプ。WebGL のフラグメントシェーダーで、和紙の繊維、竹の骨、檜の台座、壁と卓に落ちる光を描いている。
  - 下のスライダー（再生ボタン付き）で30分の夜明けを動かせる。明るさと色温度（1,800K→4,000K）が変わる。
  - 明るさに応じて、ページの文字色も夜から朝へ切り替わる。
- **素材の見せ方**：和紙、檜の柾目、真鍮のダイヤルは Canvas で手続き的に描いている（写真なし）。
- **やめたこと**：製品の絵をそれらしく描いただけのヒーロー（前作）、クリーム色の背景にテラコッタ、各セクションの英字ラベル、フェードインの連発。

## アクセシビリティと負荷

- スライダーはキーボードで操作でき、`aria-valuetext` で「6時25分、白くなる」のように読み上げる。
- `prefers-reduced-motion` のときは自動再生せず、点灯した状態で表示する。
- WebGL が使えない環境では CSS のグラデーションに切り替える。
- ヒーローが画面外にあるときやタブが非表示のときは、描画を止める。DPR は 2 までに制限している。
- 予約ダイアログはデモなので、入力内容はどこにも送信しない。
