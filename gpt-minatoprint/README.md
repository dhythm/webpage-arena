# 港の版画市

汐凪港の旧魚市場で木版を刷り、作り手の店を訪ね、波止場で食事をする一日を案内するページです。町、会場、主催者、日程、価格を含めすべて架空です。

市場の壁に貼られた二色刷りのポスターを想定しました。紙の白と魚拓の藍を基調に、太陽と入場印に山吹色を重ねています。彫り跡を残した魚を大きな明朝体の題字と向かい合わせ、会期・時刻は離れても読める太いゴシックでまとめました。小さい画面では一行の題字の下に魚版を置きます。

三つの店先は札ごとに開閉でき、気になった催しの時間・場所や料金がその場で読めます。HTML標準の開閉要素を使い、通信・保存・自動アニメーションはありません。

魚版（catch.svg）、紙目（grain.svg）、看板と各店の挿絵（HTML内SVG）は本作のために作図しました。外部素材は不使用です。書体は端末の游明朝・Noto Serif CJK JP、游ゴシック・Noto Sans CJK JP、Arial等のシステムフォントのみです。
