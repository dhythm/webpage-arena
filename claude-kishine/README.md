# 岸ねの宿（claude-kishine）

海辺の、部屋が3つだけの小さな宿。お題は [`prompts/inn.md`](../prompts/inn.md)（type `inn`）。岸ねの宿・汐見町・周辺の店や施設・料金・空き状況はすべて架空です。

## デザインの意図

対象は「静かに1〜2泊したい大人」。にぎやかな旅行サイトの文法（大きな写真のスライダー、口コミの星、限定セールの赤）を使わず、宿に着いた夕方の、音の少ない時間をページの調子にしました。

- 配色：海霧の白 `#eceff0`、沖の藍 `#1c2c35`、潮の青緑 `#2f5868`、浜の砂 `#dcd8cc`。アクセントは窓の灯り `#f0d78c` だけで、「人がいる部屋」と「選んだもの」にしか使いません。暖色クリームとテラコッタは使っていません。
- 文字：見出し・部屋の名前・献立は端末の明朝、本文と操作は端末のゴシック。キャッチコピーと献立は縦書きにして、宿の帳場の品書きのように読ませます（375px では献立だけ横書きに切り替えます）。
- 構成：情景（母屋と離れに三つの灯り）→ 客室三つ → 夜の色に切り替えた食事 → 略図と歩ける場所 → 料金表 → 空き確認と予約デモ。セクションの見出しには小さな波の線を一本だけ置き、番号は振っていません。
- 客室の区別：「汀」「凪」「磯」それぞれに間取り図を描き、図の角の丸め方・並び（左右）・眺めの説明を変えています。
- 動き：水平線の波が二本、ゆっくり横へ流れ、窓の灯りがかすかに揺れるだけ。スクロールに合わせたフェードインは使っていません。図の下の「波を止める」で止められ、`prefers-reduced-motion: reduce` では最初から止まり、ボタンも出しません。
- 予約デモ：部屋・チェックイン日（これから4週間）・泊数（一泊／二泊）・人数（一名／二名）を選ぶと、空きと架空の合計料金を出します。水曜は休館、満室日は日付から決まる擬似的なもの。送信も保存もせず、結果はページの中に表示して終わります。「滞在を問い合わせる」は `<dialog>` の中で完結するデモです。

## 画像

ラスター画像は置いていません。ヒーローの情景、三つの間取り図、周辺の略図、ロゴはすべて `index.html` に直接書いたオリジナルの SVG です（このリポジトリのために描いたもの。外部の素材は使っていません）。`thumb.webp` は `npm run thumbs -- claude-kishine` で作ります。

## フォント

フォントファイルは同梱していません。端末にある明朝（Noto Serif CJK JP / ヒラギノ明朝 / 游明朝）とゴシック（ヒラギノ角ゴ / Noto Sans CJK JP / 游ゴシック / メイリオ）を `font-family` で指定しています。外部フォントは読み込みません。

## ファイル

- `index.html` — ページ本体。必須セクション `rooms` `meals` `around` `pricing` `reserve` の id を静的に書いています。
- `style.css` — 見た目。
- `app.js` — 予約デモ、問い合わせダイアログ、周辺の略図のハイライト、波の停止。
- `meta.json` — 作品の情報。
