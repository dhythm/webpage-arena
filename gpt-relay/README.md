# Relay｜配送ダッシュボード

架空の物流サービスの現場リーダーが、配送量の変化と進行状況を一画面で比較するためのデモ。荷物を運ぶ車両を等角投影で描いたヘッダーを、配送網を見渡す画面の入口にした。棒グラフは比較する二期間を同じ尺度で表示し、ドーナツグラフは選択した範囲の内訳を示す。

`index.html` を直接開いて利用できる。期間と配送拠点を選ぶと指標、グラフ、拠点別の表が連動して変化する。動きを減らす端末設定では数字を即時更新する。

会社・拠点・数値はすべて架空。ロゴ、アイコン、配送車のイラスト、グラフは自作 SVG。フォントは端末標準のみを使用し、外部素材・通信・ビルド手順はない。
